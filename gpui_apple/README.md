# gpui-fast-apple

GPUI with gpui-fast rendering and layout optimizations.

Source and documentation: [https://github.com/feigeCode/gpui-fast](https://github.com/feigeCode/gpui-fast).

Forked from Zed's GPUI; distributed under Apache-2.0.

Use the core as `gpui = { package = "gpui-fast", version = "0.1.5" }` to preserve paths emitted by its macros.
